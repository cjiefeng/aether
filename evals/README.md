# Classifier evals (spec §5.3)

- `classifier_golden.jsonl`: the golden set. **Real ingested items only** (title, excerpt and URL
  exactly as Aether's RSS ingest stored them); Claude Code never writes or paraphrases headlines.
  Each row has a `label` (class, category, materiality) and `labeled_by`:
  `claude_proposed` until the owner reviews it, then `owner`. While any row is `claude_proposed`,
  eval results are marked **provisional**.
- `results/<prompt_version>.json`: one file per `make eval` run (committed). The worker loads them
  into `eval_runs` at startup and the Feed page shows the latest result for the current prompt.
- Adversarial cases are generated by the harness (`aether/classify/eval.py`,
  `ADVERSARIAL_SUFFIXES`): a real golden excerpt with an injected instruction appended. They are
  synthetic test inputs and are marked `synthetic_adversarial` in the results.

## Current set (M7, 2026-10-05)

61 rows from RSS items ingested on 2026-10-05 (the five configured feeds, live and recorded, plus
older pages of the three WordPress feeds via `?paged=N`): 16 SIGNAL, 45 NOISE, **0 RISK**.

**Under-sampled** (fewer than 3 rows): every RISK category, plus analyst_rating,
logical_qubit_milestone (2), roadmap_hit (2), revenue_quality (1), physical_qubit_count (1),
m_and_a, qbi_stage_change, roadmap_slip, verified_advantage. Company IR feeds and the two T2
outlets carried no RISK news for the watchlist in this window; dilution, insider and compliance
risk arrive through SEC EDGAR, which the deterministic rules classify (not part of this set). RISK
recall therefore can't be measured yet. The research backfill (first deploy with an API key) will
supply more items; then export candidates and extend the set:

```bash
make golden-candidates DB=<copy of data/aether.db>   # writes evals/golden_candidates.jsonl
```

## Owner review

For each row: check `label`, fix it if needed, and set `"labeled_by": "owner"`. Then:

```bash
make eval    # live: calls the Anthropic API with the key in .env (about $0.20 for 66 calls)
```
